# StudyDesk
A Python desktop app for keeping track of school tasks and deadlines.

# Features
- Add tasks with a course, due date, and priority
- Search tasks
- Filter by All, Open, Overdue, or Completed
- Mark tasks complete
- Delete one task or reset the whole list
- Automatically detect overdue tasks using the computer's current date
- Save tasks in a JSON file
- Show total, open, completed, and due-soon counts

- Built with Python and Tkinter.
